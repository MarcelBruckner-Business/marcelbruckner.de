notefeed 0.29.0: editable tags, claiming open feeds and better long notes

notefeed 0.29.0 is out.

  • You can change a note’s tags after posting: in the edit form, with PATCH and tags, or with notefeed update --tags in both clients. An empty list removes them. Tags that are numbers now sort as numbers, so v0.9.1 comes before v0.10.0.
  • An open feed can now get a password later. Whoever has the feed’s name can set the first one, on the settings page, with PUT /api/v1/feeds/{feed}/password or with the clients. The read link and RSS stay open. Where licenses are sold, a license can now go on a feed without a password, when it is created or later from its settings.
  • Long notes read better: headings get anchors, three or more headings get a table of contents, pictures can be sized with ![](https://notefeed.me/r/news/shot.png#width=480), code is highlighted on the page and in RSS, and Mermaid diagrams are drawn. A note posted with a name (X-Note-Name) can be fetched by that name at /r/<read id>/<name>, which always serves the newest note with that name.
  • AI assistants can now set a note’s tags with edit_note, give a note a name with post_note, and set a feed’s password or license with update_feed, which also no longer needs a title and description every time. Assistants see the changed tools only after reconnecting. In Claude, start a new chat, or remove and add the notefeed connector if they still do not show. In Claude Code, restart it.
  • Breaking: where licenses are sold, a lapsed license key is now refused with 402 instead of being accepted and doing nothing. An unknown key counts as a failed attempt, like a wrong password. Renew the license or send a valid key.
  • If you run notefeed yourself, upgrade soon: this release includes Next.js security fixes. The footer now links only the feeds listed in NOTEFEED_FOOTER_FEEDS, in that order, and none if it is unset, so set it before upgrading if you want footer links. Reserved feeds no longer hit the free tier’s limits, and euro prices show as 1.99 €.

All the details are in the release notes and on GitHub.
