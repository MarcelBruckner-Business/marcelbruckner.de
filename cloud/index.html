Cloud.

Meine eigene Cloud sind zwei Mini-PCs, die ich als vollwertige Proxmox-Hosts betreibe: Container und VMs, in sieben Zonen geplant und deployed wie eine kleine Produktionsumgebung, mit Reverse-Proxy, SSO, zentralem Monitoring und automatisierten Backups statt organisch gewachsenem Bastel-Setup.

Diese Cloud pflege ich als Code: ein Repository mit Ansible für jeden Host und jeden Container, und jede Entscheidung ist dort als ADR festgehalten, inzwischen rund 150. Diese Seite folgt diesem Stand (IP-Adressen und Hostnamen sind hier entfernt).

So läuft es

Bewusst ohne Backup bleiben 8 Container, darunter Entwicklung und Runner, deren Stand in Git liegt.

01Netzwerk & Identity

AdGuard · Caddy · Authentik

LAN-weites DNS, automatisches TLS per Reverse-Proxy und SSO vor jedem Dienst. Bewusst so deployed, dass nur dieser eine Layer aus dem Internet erreichbar ist.

02Allgemeiner App-Stack

~45 Container

Dashboard, Rezepte, CRM, RSS-Reader, Inventar-Tool und mehr, per Compose deployed und zentral aktuell gehalten.

03Build & CI

Self-Hosted GitHub Runner

Selbst betriebene Runner-Flotte für CI/CD, auf dem zweiten Host. Jeder Job startet in einem frischen, isolierten Container und hinterlässt keine Spuren für den nächsten.

04Observability

Monitoring-Stack

Prometheus, Grafana, Loki, InfluxDB2 und Beszel liefern zentrale Metriken und Logs für jeden anderen Dienst, damit Probleme auffallen, bevor sie eskalieren.

05Backup-Infrastruktur

Proxmox Backup Server

Automatisiertes, tägliches Backup für jeden Dienst, lokal als erste Stufe, danach mit versetzten Kopien außer Haus.

06Cloud, Medien & Dokumente

Nextcloud

Persönliche Cloud-Speicherung und -Synchronisation.

Immich

Foto-/Video-Bibliothek mit KI-gestützter Gesichts-/Objekterkennung.

Paperless-ngx

Dokumentenverwaltung und OCR.

Jellyfin

Mediaserver mit Hardware-Transcoding.

Frigate

NVR mit KI-gestützter Objekterkennung für Kameras.

Ebook-Verwaltung

Verwaltung der eigenen Ebook-Bibliothek.

07Persönliches & Sonstiges

Home Assistant

Smart-Home-Zentrale, per USB an Zigbee/Z-Wave angebunden.

Homelable

Inventar-/Grundriss-Tool für diese Cloud.

Dev-Sandbox

Allgemeine Docker-Sandbox für Experimente.

Trilium Notes

Persönliche Wissensdatenbank.

Mail

Ein Postfach für alle Adressen, automatisch vorsortiert.

Traureise

Meine App für Hochzeits-Websites. Sie läuft hier für die ersten Nutzer.

08Öffentliche Dienste
