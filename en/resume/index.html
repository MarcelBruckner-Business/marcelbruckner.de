04Theses

Master's thesis

Written at the TUM Chair of Robotics, Artificial Intelligence and Real-Time Systems. Learning-based methods can replace classical control in robotics, but they usually learn only a single task. I used hypernetworks to train reinforcement learning agents on several manipulation tasks in sequence, based on state representations that are themselves learned continually from camera images. In simulation the agents do not forget earlier tasks, and the image-based representation matches or beats hand-crafted state vectors.

Bachelor's thesis

Written at the TUM Chair of Software & Systems Engineering. Using suffix-tree clone detection on source code comments, I found many typical patterns that code generators write into their files. They became a repository of generator patterns that automatically classifies code as generated or manually maintained. I tested it on a reference data set and a large collection of open-source projects to determine the share of generated code.

Guided Research

“Automated Camera Stabilization and Calibration for Intelligent Transportation Systems”, in the Providentia project at the A9. Camera-based traffic infrastructure has to locate detected objects accurately in the three-dimensional world, and keep doing so in continuous operation. The work calibrates cameras automatically from targets in high-definition maps and compensates for fast vibrations and slow orientation drift with a stabilization mechanism. It was evaluated on a real-world test site.
