AI & automation

trilium-recall↗Self-hosted

Claude remembers what you wrote in Trilium: a container with keyword and meaning search, as an MCP tool and as a prompt hook for Claude Code.

trilium-llm-wiki↗

Claude Code plugin that builds and maintains an LLM wiki in Trilium, after Karpathy's pattern: schema, templates, graph, review queue and a write lock.

trilium-mcp-proxy↗Self-hosted

OAuth login for Trilium's built-in MCP server: connect any MCP client by URL and sign in with your Trilium password.

trilium-plugin↗

Claude Code plugin for Trilium: skills for notes, attributes, templates and journal, on Trilium's built-in MCP server.

karakeep-trilium-sync↗Self-hosted

Copies tagged Karakeep bookmarks, with their article text, into Trilium as notes, as sources for my LLM wiki.

paperless-mcp↗Self-hosted

MCP server for the Paperless-ngx REST API, around 80 tools, as a container sidecar.

invoiceninja-mcp↗Self-hosted

MCP server for the Invoice Ninja API with around 377 tools, as a container sidecar.

claude-marketplace↗

Curated Claude Code plugin marketplace with the plugins I use daily, plus my own.
