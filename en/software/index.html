02Engineering conventions

How I build software with AI agents: written rules for architecture, code and repository setup, which a Claude Code plugin brings into every session, so agents work to the same standards I do. It is the same question I work on as a software quality consultant: how a team makes quality a shared goal, now for a team that includes agents.

My conventions for architecture, code, working with Claude, repository setup and stacks, as a website and as a Claude Code plugin that brings them into every session: agents read the pages that apply before they design, build or review, and can audit a repository against every convention.

04Open source contributions

When a tool I use every day lacks something or has a bug, I report it to the project or send the fix. On GitHub under the account Marceltov.

Wishlist: all data through its own API Proposal, open

After the public API was declined, a second proposal that adds no upkeep: the app reads and writes its data only through its own /api, and other clients use exactly that. Rules on who may see what then live in one place instead of being spread over pages, forms and components.

Trilium Notes Merged

Notes written through the built-in MCP server or the chat now get their links recorded. Before, they were missing from backlinks and the note map.

Wishlist: public API Proposal, declined

A proposal for a small interface with personal keys, so other self-hosted apps can read wish lists. The maintainer decided against it because of the upkeep.

Trilium: sign-in with OAuth Proposal, open

A proposal that clients connect to the built-in MCP server with just its address, with no plain-text token in their configuration.

Invoice Ninja: CI tests the wrong code Fixed

A pull request's tests ran against the development branch instead of the change itself. Reported, and fixed by the project.

Trilium: partial edits for notes Proposal, open

A proposal for four improvements to the built-in MCP server: partial edits of text notes, a version check on writes, links when reading and match snippets in search.

AutoKuma: a configurable wait on connect Open

With many AutoKuma instances, every Uptime Kuma restart became a reconnect storm: no instance got its state within the fixed 9-second wait, all of them reconnected, and Kuma ran no monitor check for over two and a half hours. The wait is now configurable; the default stays as it was.

Invoice Ninja Merged

A contract test that checks the whole documented API against its OpenAPI description, and the fix for the differences it found.

giftmanager: data survives a restart Merged

Every container restart lost all gift ideas and users. The data now lives in its own directory that can be mounted. The maintainer took the code into the Docker version.

HortusFox: the app starts before its database Fixed

With Docker Compose the app started before MariaDB was ready and showed only a database error at sign-in. Reported with the cause; the app now waits for the database.

SCM-Manager: missing default branch Fixed

A new Git repository created without initialising it showed a default branch in the UI but had none, so cloning with JGit failed. Reported, and fixed in version 2.46.

Patterns in Software Engineering: summary Merged

Updated the shared summary of the TUM lecture for the winter 2017/18 exam: taxonomies, REST and object-oriented modelling.
