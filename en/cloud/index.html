Cloud

My own cloud is a mini PC that I run as a full Proxmox host: containers and VMs, planned in seven zones and deployed like a small production environment, with reverse proxy, SSO, central monitoring and automated backups instead of an organically grown tinkering setup.

The data here comes straight from a self-built inventory tool that continuously records this cloud, not a maintained wiki but the actual state (IP addresses and hostnames are removed from this view).

Build & CI deliberately runs without backup: the runner can be redeployed at any time.

Network & identity

AdGuard · Caddy · Authentik

LAN-wide DNS, automatic TLS via reverse proxy and SSO in front of every service. Deliberately deployed so that only this one layer is reachable from the internet.

General app stack

~45 containers

Dashboard, recipes, CRM, RSS reader, inventory tool and more, deployed with Compose and kept up to date centrally.

Build & CI

Self-hosted GitHub runners

A self-operated fleet of runners for CI/CD. Every job starts in a fresh, isolated container and leaves no traces for the next one.

Observability

Monitoring stack

Prometheus, Grafana, Loki, InfluxDB2 and Beszel provide central metrics and logs for every other service, so problems show up before they escalate.

Backup infrastructure

Proxmox Backup Server

Automated daily backup for every service, local as the first tier and with a staggered offsite copy as the second.

Cloud, media & documents

Nextcloud

Personal cloud storage and sync.

Immich

Photo and video library with AI-based face and object recognition.

Paperless-ngx

Document management and OCR.

Jellyfin

Media server with hardware transcoding.

Frigate

NVR with AI-based object detection for cameras.

Ebook management

Management of my own ebook library.

Personal & miscellaneous

Home Assistant

Smart home hub, connected to Zigbee/Z-Wave via USB.

Homelable

Inventory and floor-plan tool for this cloud, the data source of this page.

Traureise

My own app for wedding websites (in progress).

Dev sandbox

General-purpose Docker sandbox for experiments.

Trilium Notes

Personal knowledge base.

Own websites

3dbruckner.de and marcelbruckner.de.

Backups

Every service is backed up locally and automatically at night; a second, independent copy then moves automatically to an offsite location, two-tier, fully script-driven and without any cloud subscription.
