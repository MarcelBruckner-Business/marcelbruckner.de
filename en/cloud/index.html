Cloud.

My own cloud is two mini PCs that I run as full Proxmox hosts: containers and VMs, planned in seven zones and deployed like a small production environment, with reverse proxy, SSO, central monitoring and automated backups instead of an organically grown tinkering setup.

I keep this cloud as code: one repository with Ansible for every host and every container, and every decision is recorded there as an ADR, around 150 by now. This page follows that state (IP addresses and hostnames are removed here).

The rack

I printed the blanking panels and mounts in the rack myself.

How it runs

8 containers stay deliberately without backup, among them development and the runner, whose state lives in Git.

01Network & identity

AdGuard · Caddy · Authentik

LAN-wide DNS, automatic TLS via reverse proxy and SSO in front of every service. Deliberately deployed so that only this one layer is reachable from the internet.

02General app stack

~45 containers

Dashboard, recipes, CRM, RSS reader, inventory tool and more, deployed with Compose and kept up to date centrally.

03Build & CI

Self-hosted GitHub runners

A self-operated fleet of runners for CI/CD, on the second host. Every job starts in a fresh, isolated container and leaves no traces for the next one.

04Observability

Monitoring stack

Prometheus, Grafana, Loki, InfluxDB2 and Beszel provide central metrics and logs for every other service, so problems show up before they escalate.

05Backup infrastructure

Proxmox Backup Server

Automated daily backup for every service, local as the first tier, then with staggered copies off site.

06Cloud, media & documents

Nextcloud

Personal cloud storage and sync.

Immich

Photo and video library with AI-based face and object recognition.

Paperless-ngx

Document management and OCR.

Jellyfin

Media server with hardware transcoding.

Frigate

NVR with AI-based object detection for cameras.

Ebook management

Management of my own ebook library.

07Personal & miscellaneous

Home Assistant

Smart home hub, connected to Zigbee/Z-Wave via USB.

Homelable

Inventory and floor-plan tool for this cloud.

Dev sandbox

General-purpose Docker sandbox for experiments.

Trilium Notes

Personal knowledge base.

Mail

One inbox for every address, sorted automatically.

Traureise

My app for wedding websites. It runs here for the first users.

08Public services

Not on the home network: most products run on rented servers, and the websites are static sites.

Products

notefeed.me, gamepanion.app, noticebox and Gesetze für KI run as Docker stacks on rented cloud servers, rolled out with Ansible.

Monitoring and sign-in

A monitoring stack and single sign-on of their own in front of the dashboards, separate from the instance at home.

Websites

marcelbruckner.de and 3dbruckner.de are static sites, built and published through GitHub.

Backups

Every service is backed up locally and automatically at night; further, independent copies then move off site automatically, in several tiers and fully script-driven.
